# rm-hull/homebrew-tap

This is a Homebrew tap containing formulae for tools developed by [rm-hull](https://github.com/rm-hull).

## Usage

To use this tap, first add it to your Homebrew installation:

```bash
brew tap rm-hull/tap
```

Then you can install any of the included tools. For example:

```bash
brew install git-commit-summary
```

## Included Formulae

* [git-commit-summary](https://github.com/rm-hull/git-commit-summary) - Generate a commit summary using Gemini or OpenAI.
